How to enable AI search

Search needs SentrySearch in a separate Python 3.12 environment, a Gemini API key, and videos added to its search index. Follow “Local website” in the project README, then restart this website. Local frame indexing alone does not prepare videos for AI search.

Search indexing sends footage to Google and may incur charges. Use only footage you are authorised to share. Review the AI indexing plan below before applying it.
