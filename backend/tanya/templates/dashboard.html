          How to connect the AI

          Search needs SentrySearch in a separate Python 3.12 environment and a Gemini API key, set in the same terminal window before starting this website (see the README). Run check_setup.py for a full report.

          Quick search set-up (optional)

          Only needed for the Quick search type. The normal (thorough) search works without it. This uploads your videos to Google once, which may cost a little.

          This uploads the videos listed above to Google and may cost a little. On Google's free tier, Google may use the content to improve its products. Only continue with footage you're allowed to share. Your original videos are not changed.

          Your Yes / No answers

          When you mark a search result as a match or not, it's saved on this computer so you can measure how well search works. It doesn't retrain the AI. The export includes your searches and file names.
