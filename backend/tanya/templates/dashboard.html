    Readiness

      How to enable AI search

      Search needs SentrySearch in a separate Python 3.12 environment and a Gemini API key, set in the same PowerShell window before starting this website (see the README, “Local website (Windows PowerShell)”). Run check_setup.py for a full report.

      Prepare videos for AI search

      Sends planned footage to Google and may incur charges. Local upload, frame extraction and playback do not. Review the plan before approving.

      This sends the planned footage to Google and may incur API charges. Free-tier content may be used to improve Google products. Only continue with footage you are authorised to share. Stale search entries listed in the plan are removed; original videos stay untouched.

      Your search reviews

      Correct / Wrong / Unsure choices on search results are kept on this computer. They do not retrain the AI. Exports include queries and file names: review before sharing.
